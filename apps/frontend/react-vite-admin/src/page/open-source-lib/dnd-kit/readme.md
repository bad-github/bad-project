## drag

拖拽一个元素时，它有以下表现形式

无overlay

- 动态拖拽：拖拽时transform变，且拖拽结束后设置position相关属性，让拖拽目标处于拖拽结束位置
- 静态拖拽：拖拽时transform变，但拖拽结束后没有设置position相关属性，拖拽目标回到原位置

有overlay：此时应该全是静态拖拽

- 静态拖拽：不设置transform，不设置position相关属性，原拖拽目标始终应该在原位置（可以使用opacity决定模糊或隐藏），因为overlay已经克隆了拖拽目标的渲染

## collisionDetection

当拖动一个元素，它会不断检测是否碰到了哪些 drop 区域（即 droppable 容器）。这个碰撞逻辑由 `collisionDetection` 决定。

实际应用场景:

| 拖拽检测方式                 | 解释                                         | 适合场景                                                 |
| ---------------------------- | -------------------------------------------- | -------------------------------------------------------- |
| `closestCenter`              | 找 draggable 中心点离哪个 droppable 中心最近 | 排序、网格：拖拽排序卡片列表                             |
| `closestCorners`             | 找 draggable 元素离哪个 droppable 的角最近   | 拖动元素进入某个区域时，想要它自然地吸附到最近的角落区域 |
| `pointerWithin`              | 鼠标指针是否处在某个 droppable 区域内        | 放置容器：拖动一个卡片到不同列中                         |
| `rectIntersection`（默认值） | draggable 和 droppable 有实际区域重叠        | 宽松匹配：drag 元素大，重叠即算                          |
| 自定义函数                   |                                              | 高级判断：拖拽到 canvas、区域限制                        |

rectIntersection：

- 它会检测当前拖拽的元素矩形与其他元素矩形的相交区域
- 只要你的拖拽元素和其它元素矩形有重叠，就认为你碰到了它
- 如果没有重叠，就会回到原来的位置（比如垂直排序列表支持横向拖动时）

## 禁止放置

有以下方式可使droppable区区域禁止drag元素放置

- `useDroppable({disabled: false})`
- `onDragEnd` 中直接 return， 拦截 drop 行为
- 修改 `collisionDetection` 策略

## measuring

碰撞检测算法需要知道各个可放置区域的位置与大小。如果这些信息不准确或没及时更新，拖拽行为就会出错。measuring 允许你定制这些测量行为的策略

| 策略名           | 含义                                 | 使用场景                              |
| ---------------- | ------------------------------------ | ------------------------------------- |
| `Always`         | 每次拖拽都会测量（性能差但最准确）   | 动态内容（高度、宽度实时变化）        |
| `BeforeDragging` | 拖拽前测量一次（默认）               | 内容不会变动时最合适                  |
| `WhileDragging`  | 拖拽过程中持续测量（兼顾准确与性能） | 拖拽过程中尺寸可能变                  |
| `Never`          | 永不测量                             | 自己手动设置尺寸/位置时使用，最省性能 |

## strategy

| strategy                        | 适合布局 | 排序                                                                                                             |
| ------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------- |
| `verticalListSortingStrategy`   | 垂直列表 | Y轴中心点（取出所有元素的中心点 Y 坐标，取出拖拽元素的新中心点 Y 坐标，把所有元素按照中心点 Y 从小到大重新排列） |
| `horizontalListSortingStrategy` | 横向列表 | X轴中心点                                                                                                        |
| `rectSortingStrategy`           | 网格布局 | 元素矩形位置（XY 都算）                                                                                          |
