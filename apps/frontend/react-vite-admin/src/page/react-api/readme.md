|               | useTransition | useDeferredValue |
| ------------- | ------------- | ---------------- |
| 控制对象          | state 更新      | state 的值         |
| 使用位置          | 修改 state 的地方  | 读取 state 的地方     |
| 需要额外 state    | 通常需要          | 不需要              |
| 能知道是否 pending | ✅ isPending   | ❌                |
| 适合组件内部优化      | ✅             | ✅                |
| 适合传递 props    | 一般            | 非常适合             |
| 主动控制更新        | ✅             | ❌                |


useTransition：控制更新源头

- 触发更新的任务就是该回调
- 知道哪个更新昂贵
- 多个 state 一起更新
- 应用场景
  - 路由切换
  - Tab切换
  - 大列表刷新
  - 编辑器内容更新


useDeferredValue：不控制产生值的地方，关注这个值的消费者是否可以晚一点看到新值
- 接收外部数据
- 优化某个组件
- 不想改变数据来源，只是优化消费者
- 场景
  - 大表格组件
  - 图表组件
  - 第三方组件包装
  - 微前端子应用数据传递
