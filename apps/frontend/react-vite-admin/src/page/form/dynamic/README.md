# 联系人管理

使用 `useFieldArray` 维护 1–5 位联系人。左侧填写姓名和邮箱，并删除或移动联系人；右侧集中演示数组 API，观察表单状态和 JSON。

联系人采用紧凑行布局，姓名、邮箱及上移/下移/删除操作放在同一行；空间不足时操作换行。不再为每行显示独立标题和渲染 ID，ID 统一在右侧数组结构中观察。

列表末尾“新增”添加一位空白联系人，不自动聚焦；右侧 API“末尾新增”会同时填入姓名和邮箱，也不自动聚焦。每行“填充”按该联系人的 ID 写入预设姓名与邮箱，保留业务 ID 和渲染 ID，更新 dirty、touched 并校验数组，不移动焦点。这两个新增入口都受最多 5 人限制。

## 数组操作

| 操作               | API                          | 影响                                                            |
| ------------------ | ---------------------------- | --------------------------------------------------------------- |
| 末尾新增、批量新增 | `append`                     | 传完整对象或对象数组；本页设置 `shouldFocus: false`，不自动聚焦 |
| 开头新增           | `prepend`                    | 原有行的路径索引后移，自动聚焦新增行的姓名                      |
| 选中行前插入       | `insert`                     | 在指定索引插入完整对象，自动聚焦新增行的姓名                    |
| 删除、清空         | `remove(index)` / `remove()` | 同时处理对应数组值和交互状态                                    |
| 上下移动           | `move`                       | 移动一项，中间各项依次挪动                                      |
| 更新姓名           | `setValue`                   | 修改叶子字段，保留行实例；显式设置校验、dirty 和 touched        |
| 更新整行           | `update`                     | 传入完整行值，目标行获得新 `field.id` 并重新挂载                |
| 重置为 2 人        | `replace`                    | 载入两位预设联系人，重建渲染标识，保留原有默认值基准            |
| 恢复初始表单       | `reset`                      | 恢复一行空白联系人，清理错误、交互和提交状态                    |

## 标识与订阅

`contactId` 是创建联系人时分配的业务 ID，在当前运行环境内递增且不回收。姓名标签显示“联系人{contactId}姓名”，因此空白联系人交换、移动后也能看到编号跟着数据移动。操作目标以 ID 为选项值，执行 RHF 数组操作时再查找当前索引，排序后仍指向同一联系人；目标被删除或替换后回退到当前第一位。它随表单数据提交，更新姓名或整行时保留；载入预设联系人分配新 ID，恢复初始表单则恢复最初那位联系人的 ID。编号不要求连续，不承担跨页面刷新或数据库持久化唯一性。

`field.id` 仅作为稳定 React key 和输入框标签标识。它不是业务主键，不会自动进入提交数据；路径始终为 `contacts.${index}.name` 等当前索引。排序时保留原行标识，更新整行、替换或重置时标识会变化。

`fields` 反映数组结构，不是实时输入值。右侧用 `useWatch` 订阅实时值，操作整行时用 `getValues` 获取最新输入；快照另行克隆。`useFormState` 订阅错误、dirty、touched 和提交状态，问号说明各状态含义。`isDirty` 比较当前值和默认值，不等于“曾点击过操作”。

## 校验与生命周期

Zod resolver 统一处理必填、格式、数量以及忽略大小写的重复邮箱校验。失焦时校验整个数组，确保两行重复邮箱提示一起更新；已有错误或提交过之后，结构变化也会重新校验。右侧“校验全部”不提交、不增加提交次数。

`shouldUnregister` 保持 `false`，避免字段数组重排、更新时因卸载注销数据。实际删除交给 `remove`。新增空白行不会继承已删除行的数据。

保存结果只放在当前页面内存中，没有远程请求或持久化。保存不改变默认值基准，也不会自动把 `isDirty` 清零。

## 文件

- `index.tsx`：表单实例、唯一的字段数组实例、左右布局及提交。
- `contact-row.tsx`：当前索引路径注册、稳定标签、字段错误及行操作。
- `form-observer.tsx`：数组 API、状态说明、折叠 JSON 与快照。
- `form-model.ts`：类型、默认值、示例、统一校验及错误序列化。
- `form-model.test.ts`：数量边界、跨行冲突、真实 RHF 提交和重置。
